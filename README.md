 # smart expense tracker 

This is a simple command-line expense tracking project built using Python.
I created this project to practice Python programming, data handling, and basic data analysis by solving a real everyday problem — tracking personal expenses.

The program allows users to record daily spending, view summaries, and understand where money is going. It also generates charts to visualize spending patterns.



## what this project can do

Add daily expenses
View all saved expenses
Calculate total spending for a selected month
Show spending by category
Identify the category where most money is spent
Estimate next month’s spending based on past data
Show warnings for high spending
Generate and save charts for visualization



## Technologies used

Python
CSV file handling
Matplotlib for charts



## Project files


main.py        → runs the program and menu system  
tracker.py     → handles expense logic and calculations  
charts.py      → creates and saves charts  
expenses.csv   → stores expense data  
README.md      → project information  




## How to run this project

1. Download or clone the repository
2. Open terminal inside the project folder
3. Install required library:


pip install matplotlib


4. Run the program:


py main.py


Follow the menu options shown in the terminal.
